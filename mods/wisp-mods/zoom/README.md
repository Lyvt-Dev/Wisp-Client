# Zoom 1.0.0

Wisp client module, API 1. Requires Wisp 0.7 or later.

Install from the launcher's **Mods > Install Zoom**, or build this folder with
`cargo wisp-mod build` and import `target/wisp-mod/zoom.amod`.

Hold **Z**, then scroll to adjust zoom. Release Z to return to the normal camera.
Rebind the key in **Options > Mods > Zoom > Settings**. Starting magnification,
smooth zoom and proportional mouse sensitivity are configurable.

Wheel zoom goes beyond 10×, with floating-point precision guards.
See [the package format and controls](../../../docs/amod.md).
