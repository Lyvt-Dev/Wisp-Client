# Wisp Launcher 0.10.0

- Resource-pack overlays retain the prepared resource archive for unchanged files,
  avoiding thousands of individual vanilla model and texture reads. Overrides,
  merged files, filtering, cache hits and pack changes remain reflected in reads.
- Native static Nuit schema-1 skies: square-textured cubes, monocolor layers,
  Overworld background and vanilla sun/moon/star visibility controls. Transparent
  sky artwork uses normal alpha blending and the correct face orientations.
- Custom sky faces are capped at 1024 pixels to bound atlas memory on smaller GPUs.
- Packs with no assets are identified in the game screen and skipped when building
  the resource overlay. Changing only metadata does not add missing textures.
- Reload logs include timing checkpoints for diagnosing remaining delays.

Animated Nuit layers, custom shader overrides, advanced clocks/fades, biome/weather
conditions and custom celestial textures are not supported in this initial native
implementation. Unsupported layers are reported rather than applied globally.
The existing native shaders, login, instances and user data are preserved.

This release includes no user artwork or Minecraft assets. Resource packs must
contain their actual assets; metadata-only packages cannot change textures.
