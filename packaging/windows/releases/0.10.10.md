# Wisp Launcher 0.10.10

- Sounds that a copy left out are found again. The launcher's check now looks at every sound
  file the game names, not only `sounds.json`, so block breaking, hits and fight sounds come back
  after an interrupted copy. Preparing the game again fills in the missing files.
- Server resource packs have no size limit any more. A required pack over 250 MB used to fail
  and disconnect you from the server.
- A server pack that is sent again under the same ID no longer makes the game reload its
  resources every few seconds.
- The game logs each scoreboard team packet it receives, for tracing team prefixes on nametags
  and in the player list.

Existing instances, login, coins and items are preserved.
