# Wisp Launcher 0.10.8

- Sound comes back after your audio device drops out. When Bluetooth headphones switched off
  or a device was unplugged while no other output was there, the game stayed silent until it
  was restarted, even after the device returned. It now tries the output again every second
  until one opens.
- Resource packs: GUI sprites with `tile` scaling in their `.png.mcmeta` now repeat as in
  Java Edition instead of stretching.
- The resource pack support list (`docs/resource-packs.md`) now matches the game: TrueType
  fonts, fonts chosen by text, blended animations, credits, villager hats, worn armour trims,
  the locator bar and pack post effects all work. Packs' core shaders still only run for the
  GUI text and the block outline.

Existing instances, login, coins and items are preserved.
