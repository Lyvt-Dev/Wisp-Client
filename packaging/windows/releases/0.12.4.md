# Wisp Launcher 0.12.4

- **New Mods page:** all 37 built-in client features are tiles with a short description and an
  on/off switch. Click a tile to turn it on or off.
- **Categories:** HUD, Info panel, Combat, Visual and Utility tabs, a search box and an
  "Only on" filter.
- **Wisp modules:** Zoom and imported .amod files have their own cards with install, update,
  on/off and the Zoom options.

Existing instances, login, coins and items are preserved.
