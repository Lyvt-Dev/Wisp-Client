# Wisp Launcher 0.12.5

- **New Shaders page:** the shader you use is shown large with its preview and features, a
  one-click Low / Balanced / High quality switch and Turn off. With no shader on, the page says
  so.
- **Your shader packs:** a grid with an "Off (vanilla)" tile and a card for each pack, with
  Use, Install or Update, plus search and Shadows / Reflections / Clouds filters.

Existing instances, login, coins and items are preserved.
