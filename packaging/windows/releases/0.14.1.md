# Wisp Client 0.14.1

- **Automatic updates:** the launcher looks for a newer Wisp Client release when it starts,
  downloads the installer in the background, checks it against the release's checksum and
  installs it once no game is running, then opens again. Settings › General › Updates turns it
  off. Players on 0.14.0 install this version by hand once; later versions arrive by themselves.
- **Wisp Menu (Right Shift):** the header shows the feather on a black tile, and the buttons that
  were violet are black and white like the rest of the client, so Edit HUD is readable again.
- **Wisp badge:** every player now wears Wisp's feather before their name. It is part of the
  client, so it isn't in the Shop and can't be taken off, and it shows even with cosmetics hidden.
  The Star, Crown and Moon badges are gone from the Shop.
