# Wisp Client 0.14.3

- **Update window:** when the launcher finds a new version, a small window opens that says which
  version is coming and shows the download in percent, then the installer's own progress while
  it installs. Wisp Client opens again by itself afterwards.
- **Wavy Capes on Shop capes:** capes from the Shop now bend, fly out behind you and wave as you
  move, like the Mojang cape (Wisp Menu › Visual › Wavy Capes).
- **Your own name tag shows your rank:** on servers that keep ranks in the player list instead of
  the name tag teams, your own name tag (the Own Name Tag extra, in third person) now shows the
  name the player list shows.
