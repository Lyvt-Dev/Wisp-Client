# Wisp Client 0.14.4

- **Ranks in other players' name tags:** on servers that keep ranks in the player list instead
  of the name tag teams, every player's name tag now shows the name the player list shows (rank
  and all), not only your own.
- **Session renewal without a restart:** the Minecraft session lasts a day. While the launcher
  is open, it now renews the session of the running game before it ends, so you can keep
  joining servers in a long session. If a server still says "invalid session", wait a few
  seconds and join again.
