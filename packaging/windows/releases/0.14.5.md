# Wisp Client 0.14.5

- **Linux:** Wisp Client now comes as an AppImage, `Wisp-Client-0.14.5-x86_64.AppImage`, with the
  launcher and the game in one file. Make it executable (`chmod +x`) and run it; nothing to
  install. It needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later) and a
  Vulkan driver. On Linux the launcher doesn't update itself yet and keeps the sign-in only while
  it is open: download the new AppImage for an update.
- **Play sooner on a fresh install:** when there is no instance yet, the launcher starts
  installing Minecraft as soon as it opens (right after sign-in when you aren't signed in).
- **Max Render client module:** `max_render.amod` lifts the render distance cap of 128 chunks up
  to 2,147,483,647. Download it from this release and import it in **Mods > Import .amod**. Far distances need a lot of memory and
  processing power, and servers still send only their own view distance.
