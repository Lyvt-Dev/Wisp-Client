# Wisp Client 0.14.8

- **Voice chat now connects to real servers.** Every released Simple Voice Chat (2.6.x, including
  the Paper plugin) speaks an older protocol version than Wisp did, so the server's answer was
  rejected and voice chat stayed "not available". Wisp now speaks both the released version and
  the 2.7 prereleases and picks the one the server uses.
- **Teleports no longer leave you floating in an invisible chunk.** After `/rtp`, `/spawn` or a
  home teleport on some servers, the chunk you landed in could stay missing until you rejoined.
  Chunks the server moves out of view are now kept hidden, as in vanilla, instead of thrown away,
  so they come back when the view returns.
