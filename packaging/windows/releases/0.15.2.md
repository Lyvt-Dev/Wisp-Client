# Wisp Client 0.15.2

- **Wisp for Android 0.15.2** is out on the same release page (`Wisp-Client-0.15.2-android-arm64.apk`):
  it runs much smoother on phones, the app no longer closes when a thumb slides off the screen,
  the touch buttons sit away from the edges, the joystick walks the right way and the app has a
  new home screen. Phones that already have the game files keep them.
- The launcher updates itself to 0.15.2; nothing changes on the PC.
