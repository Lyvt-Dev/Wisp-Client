Wisp Launcher 0.7.0 bundles the native Rust Minecraft engine and resource preparer in a Windows x64 installer.

- Adds Wisp `.amod` client modules, starting with Zoom. Open **Mods > Install Zoom**, start Minecraft, then hold **Z** and scroll to adjust magnification beyond 10×.
- Adds per-instance mod installation, enable/disable, smoothing and sensitivity settings.
- Removes the old featured SMP entry once, backing up the original server list and preserving other servers.
- Retains Microsoft sign-in, owned-game installation, the violet launcher design and hidden game console.

Close Minecraft and Wisp before running the setup. Existing profiles and worlds are preserved.
Download the **Setup-x64.exe** asset; the `.sha256` file contains its SHA-256 checksum.

Validation: 145 targeted tests and strict Clippy passed locally. In-world visual zoom validation remains manual.
This first client-module API supports Zoom; it does not run Java Fabric/NeoForge JARs.
