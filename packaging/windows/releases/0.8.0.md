# Wisp Launcher 0.8.0

The Mods, Versions and Shaders pages now follow the supplied Wisp catalog designs,
with scenic headers, filters, search, tabs, sorting and grid/list controls.
All counts, account details, installed packages, instances, favourites and launch
history come from real local data. Java loader/catalog mock entries are not shown.

- Browse, install, enable and configure the native Zoom `.amod` module. Updates
  preserve disabled state and custom settings; bulk selection can enable modules.
- Manage actual instances, filter by native/imported or modded/vanilla state,
  favourite profiles and see recorded successful-launch history.
- Install and select native shaders per instance, import validated `.hshader`
  packages, and choose Aurora's Low, Balanced or High preset.
- Includes **Wisp Aurora 1.0.0**, an original native WGSL shader with soft shadows,
  animated reflective/refractive water, block-shaped clouds, waving foliage,
  coloured lighting, bloom, light shafts and edge smoothing. Inspired by the
  vanilla-friendly cinematic goals of Complementary Reimagined; this is not its
  source, a Java shader port, or identical visual output.
- Bundles the native Rust engine and resource preparation tools. Shader effects
  remain off until selected. Existing worlds, account files and other graphics
  preferences are preserved.

Download the Windows x64 Setup below. The standalone Aurora package is optional;
the same shader is built into the launcher's catalog. SHA-256 sidecars accompany
both downloads. Minecraft resources still require your own licensed account.
