# Wisp Launcher 0.9.0

This release builds on 0.8.0 and keeps Microsoft login, instance catalogs,
native Zoom modules, Aurora shaders and the existing Windows upgrade path.

- The Mods page includes per-instance built-in controls for Full Bright,
  FPS Counter, Apple Skin, Mouse Tweaks, SmartF3, Shulker Preview / Peek,
  Armor Status, Mod Menu, Fast Items and Hitbox.
- The optional Wisp HUD uses translucent purple panels and sunset accents.
  It is off by default, follows GUI scale and hides with F1.
- Right Shift opens Options / Wisp / Extras when Mod Menu is enabled.
- Launcher and in-game controls share saved preferences. Launcher changes
  are locked while playing, and preserve unrelated settings.

These are native Rust implementations, not bundled Fabric/Forge Java mods.
Apple Skin provides hunger/saturation and held-food restoration readouts;
Armor Status shows equipped item names and remaining durability; SmartF3
provides compact FPS/coordinates; Fast Items draws one model per dropped
stack. Shulker previews show contents already known to the client. The HUD
uses tinted panels rather than scene blur, and is not a copy of NoRisk's UI.

Download the Windows x64 Setup below. The engine and preparation tools are
included; Minecraft assets and prepared resources are not. Existing worlds
and account files are preserved. SHA-256 sidecars accompany the downloads.
